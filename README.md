# Jit Polycoat Enterprise — public catalog assets

Swatches + `catalog.json` for the decorative CFB trade catalog (750 designs / 1,587 SKUs).

Trade codes end **MG** (Match Graphics) or **BY** (Baaya). Official design names come from Match product titles and Baaya `baaya_name` — SKU-only titles are left as numbers.

The trade-portal **source** stays private in `decorative-cfb-trade-portal`. This repo is public so the live catalog can show images.

Live: https://jit-polycoat-catalog.vercel.app
